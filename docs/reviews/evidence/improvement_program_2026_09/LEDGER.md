  (Part A, 245), one per red local-gate node at `6459f1a6` (Part B, 51), one per side
  finding registered at Wave 0 (Part C, W0-N1..N10), plus the Wave 0 rulings and the
  Park register (Part D). A row leaves this ledger only as **CLOSED** (release named in
  `closure`, with probe + flipped/added pin + guard), **PARKED** (§15 ruling with a
  successor owner) or **EXCLUDED** (§15; `fixed` / `not_reproducible`). Nothing labelled
  partial, carried, watch or to-be-decided counts as closed (§3 item 7); no row has an
  empty or undecided owner (D10 / §6 exit criteria).

  [`tools/make_ledger.py`](tools/make_ledger.py) from `INVENTORY.json`, `gate_triage.json`
  and the program's own slot headings (§6–§13), §12, §15 and §16 — cid → slot comes from
  the headings, not from the §16 map, and Part E prints the cross-check. Regenerate with
  `python3 docs/reviews/evidence/improvement_program_2026_09/tools/make_ledger.py`;
  hand-edit only the header, Part C and Part D (the generated blocks are marked).
- **Columns:** `owner slot` = the wave.slot (or `Park P-n` / `Excluded` / `R`) that closes the
  row; `owner symbol` = the `file.py#symbol` the slot brief names as the single holder of the
  rule (D2); `guard` = the ratchet / drift-lock / matrix / counter that forbids re-duplication
  (run against a synthetic offender in the shipping slot); `closure` = empty until a release
  closes the row ("release vX.Y.Z" + evidence dir).
- **Status vocabulary (Part A):** `live` (re-reproduced at HEAD vs 5.3.15 on 2026-09-06),

  (excluded, §15).
